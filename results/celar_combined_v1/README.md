# CELAR 联合立项结论

**GO_TO_MUJOCO_FULL_PILOT**

| 阶段 | 门控 | 关键事实 |
|---|---|---|
| C0 | 通过 | 配对和任务泄漏为 0，三本体专家动作可执行 |
| C1 | 通过 | 相似动作 R@1 0.911，共享 AE 0.550 |
| C2 | 通过 | 语义误差比 1.107，可执行率比 0.860 |
| C3 | 通过 | 最终成功率 CELAR 0.715，原生 0.375 |
| C4 | 通过 | 5-shot 新本体 decoder 语义误差降低 26% |

C3 采用 49,152 个在线环境步。CELAR 达到 50% 成功率的平均步数为 36864，原生 PPO 为 42325；最终成功率差值为 +0.340，95% CI [+0.229, +0.396]。共享 decoder PPO 的最终成功率为 0.535。

分组审计覆盖 18 个种子 × 本体 × 任务配对；CELAR 相对原生 PPO 的平均成功率差为 +0.294，83.3% 的方向为正，多数方向门槛通过。

## 结论边界

所有结果来自二维跨本体运动学/抓放代理，不含 MuJoCo、LIBERO、真实 RGB-D、接触动力学或真机。联合结论只支持进入 MuJoCo C0–C3 全量试点，不能作为论文级机器人样本效率结论。
